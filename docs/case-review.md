# 판단 사례와 변경 근거

아래는 **판단 변화 또는 미해결 경계**를 드러내기 위해 선택한 합성 이메일 사례입니다. 전체 52건의 무작위 표본이 아닙니다. 각 사례는 서로 다른 검토 단계에서 기록됐으므로 **동일 조건의 전후 정확도 실험으로 해석하지 않습니다**.

## 2. 새 합성 이메일 6건에 적용한 기록

v0.5 기준 정리 후 사용자가 먼저 047~052를 판단하고, 이후 **AI 검토 의견을 참고**하여 048과 052의 최종 판단을 수정했습니다.

| ID | 사용자 최초 판단 | 최종 판단 | 확인한 내용 |
| --- | --- | --- | --- |
| 047 | 공지 전달 | 공지 전달 | 의무적 행동이 있어도 자료·검토 결과의 회신 요구와 구분 |
| 048 | 자료 제공·제출 | **자료 요청** | 세금계산서 자체 발행이 아니라 발행 정보의 전달을 요구. 조건부 표현만으로 제외하지 않음 |
| 049 | 계정 생성/권한 요청 | 동일 | 라이선스 할당을 이용 권한 요청으로 해석 |
| 050 | 자료 제공·제출 | 동일 | 구체적인 일정표·수량 자료 제공, 별도 승인·수정 요구 없음 |
| 051 | 검토·수정 요청 | 동일 | 기존 신청서의 특정 표기를 확인하고 답신하도록 요구 |
| 052 | 자료 제공·제출 | **보류 — 범위 밖** | 도서 구매·비치 완료 안내를 자료 제공과 구분 |

**변경된 최종 라벨: 6건 중 2건.** 이는 판단 변경 기록이며 정확도 또는 성능 개선 지표가 아닙니다.

## 3. 추가 확인이 필요한 항목

- **051:** 제목은 사명, 본문은 부서명 영문 표기를 다룸. 제목·본문 불일치.
- **047:** 법령·과태료 관련 생성 문구의 사실 여부는 검증하지 않음.
- **044:** 시스템 오류 사후 보고와 공통 `자료 제공·제출`의 경계는 미해결.
- **051:** 특정 표기 확인 요청과 단순 사실 정보 요청의 경계는 추가 검증되지 않음.
